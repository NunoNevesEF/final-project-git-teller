# final-project-git-teller

Git-Teller is a full-stack application that analyzes Git repositories and generates detailed reports on project activity and contributor performance. The platform combines traditional Git metrics obtained through JGit with AI-powered insights generated by Large Language Models (LLMs). It supports repository analysis, interactive visualizations, PDF report generation, scheduled analyses, and report history. The application is available on both Web and Android through a shared backend built with Kotlin and Spring Boot, while the frontend is developed using React Native and Expo.
